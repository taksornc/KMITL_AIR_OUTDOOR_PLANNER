# เกี่ยวกับระบบ KMITL Outdoor Planner

- พื้นที่: วิทยาเขต สจล. ลาดกระบัง เท่านั้น พยากรณ์เป็นค่าเดียวทั้งวิทยาเขต ไม่แยกรายจุดหรือรายตึก
- ฝุ่นตอนนี้: ค่ากลาง (มัธยฐาน) จากเซนเซอร์ KMITL Smart Pole ภายในวิทยาเขต (SCiRA) อัปเดตทุกชั่วโมง
  ถ้าเซนเซอร์ไม่พร้อม ระบบจะใช้สถานีของกรมควบคุมมลพิษ (Air4Thai) ที่ใกล้ที่สุดแทน (รพ.ลาดกระบัง ห่างราว 1 กม.)
- พยากรณ์ฝุ่น: โมเดล machine learning (Random Forest) ที่กลุ่มพัฒนาเอง ทายรายชั่วโมงล่วงหน้าไม่เกิน 7 วัน
  เทรนจากข้อมูลย้อนหลังประมาณ 3 ปี ใช้พยากรณ์อากาศ (ลม ฝน การระบายอากาศ ความชื้น) เป็นข้อมูลนำเข้า
  พยากรณ์ช่วงแรกเริ่มจากค่าจริงตอนนี้ แล้วค่อย ๆ ใช้ค่าจากโมเดล
  ยิ่งทายไกล ความแม่นยิ่งลดลง (1 วัน = ค่อนข้างแม่น, 2–3 วัน = ปานกลาง, 4–7 วัน = ใช้ดูแนวโน้ม)
- พยากรณ์ฝน อุณหภูมิ ลม UV: จาก Open-Meteo โดยตรง ไม่ได้มาจากโมเดลของระบบ
- คำตัดสินว่ากิจกรรม "เหมาะ / พอได้ ถ้าเตรียมตัว / ไม่แนะนำ" มาจากเกณฑ์ที่เขียนไว้ชัดเจน
  ยิ่งออกแรงมากหรือมีคนกลุ่มเสี่ยง เกณฑ์ฝุ่นยิ่งเข้มขึ้น AI ทำหน้าที่อธิบายเท่านั้น ไม่เปลี่ยนคำตัดสิน
- ข้อมูลฝุ่นย้อนหลังที่ใช้เทรนเป็นค่าจากแบบจำลอง (CAMS ผ่าน Open-Meteo) ซึ่งเฉลี่ยพื้นที่กว้าง
- ระบบให้ข้อมูลประกอบการตัดสินใจ ไม่ใช่คำวินิจฉัยทางการแพทย์
